
# Employee Attendance Management System (EAMS)

## 1. Introduction
EAMS is a web-based system developed to help companies manage employee information and attendance records efficiently.

## 2. Project Objectives
- To manage employee information.
- To record employee attendance.
- To monitor employee attendance status.
- To generate attendance reports.

## 3. System Features
- Administrator Login
- Employee Login
- Employee Management
- Attendance Management
- Attendance Reports
- Employee Dashboard

## 4. Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap 5
